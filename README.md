# Youni4st для Android — 0.1.0

Нативный Android-проект на Kotlin + Jetpack Compose, созданный по пяти предоставленным скриншотам и материалам существующего Telegram Mini App. Это основа для дальнейшей совместной разработки.

## Что реализовано

- Главная с оригинальным логотипом, карточками направлений и плавающей нижней навигацией.
- Подбор 49 вузов: фильтры по баллу ЕНТ (0–140), городу и направлению, подробные карточки, специальности, избранное.
- Каталог из 5 вакансий: фильтры, описания и локальные черновики откликов.
- 10 наставников: фильтры по специализации и стоимости, карточка в нижней панели, локальный черновик записи.
- Редактор резюме: имя, телефон, зарплата, город, опыт, образование, навыки, выбор фотографии из системной галереи. Сохранение на устройстве, проверка номера, защита от случайной потери несохранённых изменений.
- Профиль, избранное, черновики, индикатор заполнения резюме.
- AI Сократус: клиент реального `/api/chat`, история на устройстве, состояние загрузки, повтор при ошибке, очистка истории.
- 30 образовательных программ, материалы о грантах, IELTS и ЕНТ из исходного Mini App.
- Русский, казахский и английский интерфейс и каталог; выбранный язык сохраняется.
- Каталоги, иллюстрации и основные функции доступны без интернета. Чат требует доступного сервера.

## Установка APK на телефон

Готовая тестовая сборка передаётся отдельно как `Youni4st-0.1.0-debug.apk`.

1. Перенеси APK на Android-телефон через USB, облачный диск или сообщение самому себе.
2. Открой файл на телефоне и, если Android попросит, разреши установку этому приложению-источнику.
3. Установи Youni4st и открой его. Для каталогов вход и интернет не требуются.

Сначала проверь главную, подбор вузов, карточку наставника и сохранение резюме. Список выполненных проверок и ограничений находится в `docs/VERIFICATION.md`.

## Запуск в Android Studio

1. В Android Studio выбери **File → Open** и открой папку `youni4st-android`.
2. Выбери встроенный JDK Android Studio (JDK 17 или 21).
3. Установи Android SDK Platform 36 и Build Tools 35.0.0 через SDK Manager, если их ещё нет.
4. Дождись Gradle Sync и нажми Run на подключённом Android-телефоне или эмуляторе.

Минимальная версия телефона: **Android 8.0 / API 26**. Целевая версия: API 36. Package ID: `kz.youni4st.app`.

Сборка из терминала Windows:

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

На macOS/Linux: `chmod +x gradlew`, затем `./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`.

APK создаётся в `app/build/outputs/apk/debug/app-debug.apk`. Debug-сборка предназначена для установки и проверки, а не публикации в Google Play. Для публикации потребуется отдельная release-подпись владельца проекта.

Инструментальные UI-тесты при запущенном эмуляторе/подключённом устройстве:

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

## Сервер и границы первой версии

В `app/build.gradle.kts` задан `API_BASE_URL`: `https://youni4st-beckend.onrender.com`. Адрес найден в опубликованном Mini App. Его можно изменить и пересобрать приложение. Секреты и ключи сервисов клиенту не нужны.

Чат отправляет `{ "message": "…", "history": [{ "role": "user", "content": "…" }] }` и читает поле `reply`. История ограничена десятью сообщениями на запрос, локально хранятся последние сорок. Содержимое отправляется серверу только после нажатия пользователем кнопки отправки. Доступность сервера и работа AI-провайдера проверяются отдельно; приложение не подменяет ошибки сервера придуманными ответами.

**Отклики и консультации пока только локальные черновики.** Они не отправляются работодателям, наставникам, в Telegram или CRM. Это явно указано на соответствующих экранах. В предоставленном backend отсутствуют API создания отклика, записи к наставнику и полноценная авторизация Android-клиента.

Резюме и избранное сохраняются на телефоне. После удаления приложения локальные данные удаляются; облачная синхронизация и экспорт PDF в этой версии не подключены. Каталоги встроены в APK; актуальность дат, цен и вакансий не подтверждена отдельно. Данные меняются заменой JSON-файлов в `app/src/main/assets`.

## Структура

- `app/src/main/java/kz/youni4st/app/data` — чтение каталогов, локальное хранение, клиент AI API.
- `AppViewModel.kt` — состояние, избранное, резюме, чат.
- `ui/Theme.kt`, `ui/Components.kt` — оформление и общие компоненты.
- `ui/CatalogScreens.kt` — главная, вузы, работа, наставники.
- `ui/DetailScreens.kt` — карточки, статьи, профиль и сохранённые материалы.
- `ui/PersonalScreens.kt` — чат и редактор резюме.
- `app/src/test` — фильтры, сохранение данных, локализация, контракт AI API.
- `app/src/androidTest` — основные пользовательские сценарии.
- `docs/SOURCES.md` — происхождение данных и визуальные допущения.
- `docs/BACKEND.md` — подключение сервера и следующие шаги.

Следующий этап: пройти приложение на твоём телефоне, уточнить внешний вид, затем подключить вход, защищённую синхронизацию и реальную отправку заявок.
